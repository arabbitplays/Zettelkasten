# The Go Programming Language

## Introduction

- go is designed to be as lightweight and stable and to conquerer the complexity of big projects
- influenced by C and [[Communicating Sequential Processes (CSP)]]
- strings natively support unicode
- the `go` CLI command bundles the must important functionalities around the language, like building, testing and formatting the code
	- the `goimport` tool automatically handles imports, get it with `go get golang.org/x/tools/cmd/goimports`
